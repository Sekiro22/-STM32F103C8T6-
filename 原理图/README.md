# 原理图

本目录保存 hWatch 硬件原理图导出文件，用于查看电路设计、排查硬件问题和继续开发硬件版本。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `SCH_Schematic1_2024-08-15.pdf` | 2024-08-15 导出的原理图 PDF |

## 查看重点

- STM32F103C8T6 最小系统：供电、复位、时钟和下载接口。
- OLED 接口：确认 I2C 引脚、供电电压和上拉关系。
- 按键输入：确认 PA0、PA1、PA2、PA8、PA9 与软件工程中的 EXTI 配置一致。
- 蜂鸣器：确认 PB8/TIM4_CH3 与驱动代码一致。
- 传感器接口：确认 BMP280/BME280 的 I2C 地址、供电和引脚连接。
- 电源路径：确认电池、电源管理和低功耗相关电路。
