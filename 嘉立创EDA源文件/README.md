# 嘉立创 EDA 源文件

本目录保存 hWatch 的嘉立创 EDA 工程源文件压缩包，用于继续修改原理图和 PCB。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `hWatch_2024-08-12_16-13-03.zip` | 嘉立创 EDA 导出的 hWatch 工程源文件 |

## 使用方式

1. 打开嘉立创 EDA。
2. 选择导入工程或打开本地工程压缩包。
3. 导入 `hWatch_2024-08-12_16-13-03.zip`。
4. 修改原理图或 PCB 后，重新导出原理图 PDF、BOM 和 Gerber。

## 维护注意

- EDA 源文件是硬件修改的主来源，Gerber、BOM 和原理图 PDF 都应从它重新导出。
- 修改后建议按日期或版本号另存，例如 `hWatch_YYYY-MM-DD_HH-MM-SS.zip`。
- 如果仅更新 Gerber 或 BOM，而没有更新 EDA 源文件，后续维护会失去可追溯性。
- 重大硬件改动建议在根 README 或本 README 中记录变更摘要。
