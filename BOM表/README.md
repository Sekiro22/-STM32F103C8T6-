# BOM 表

本目录保存 hWatch 硬件的物料清单文件，用于元器件采购、焊接前核对和后续硬件版本维护。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `BOM_Board1_PCB5_2024-08-15.xlsx` | PCB5 版本导出的 BOM 表，包含器件位号、型号/封装、数量等生产采购信息 |

## 使用建议

1. 下单 PCB 或准备焊接前，先用此表核对元器件数量和封装。
2. 如果后续修改原理图或 PCB，需要重新从 EDA 工具导出 BOM，并保留日期或版本号。
3. 如果替换器件型号，建议在 BOM 中额外记录替代料原因，避免后续无法追溯。

## 维护注意

- 不要只改 Excel 文件名而不更新本 README。
- 如果 BOM 与原理图或 PCB 不一致，以最新 EDA 源文件重新导出的 BOM 为准。
- 对关键器件，如 MCU、OLED、传感器、电源芯片和连接器，建议记录可替代型号。
