# STM32F103C8T6 环境监测手表

这是一个基于 **STM32F103C8T6** 的环境监测手表项目。仓库按硬件、软件工程和文档资料分层维护，当前已归档的 Keil 工程位于 [`软件工程/`](./软件工程/)。

## 项目目标

- 使用 STM32F103C8T6 作为主控。
- 使用 128x64 OLED 显示时钟、菜单、秒表等界面。
- 通过实体按键完成菜单切换、确认、返回和主页跳转。
- 预留 BMP280/BME280 温压传感器驱动，用于后续天气/环境信息页面。
- 支持蜂鸣器、低功耗休眠和基础 UI 动画。

## 快速开始

1. 进入 [`软件工程/`](./软件工程/)。
2. 使用 Keil MDK/uVision 打开 `Project.uvprojx`。
3. 确认目标芯片为 `STM32F103C8`。
4. 编译 `Target 1`。
5. 使用 `Objects/Project.hex` 烧录到开发板。

## 当前软件功能

- 时钟主界面：读取 RTC 并显示日期、星期、时分秒。
- 横向主菜单：通过 U8g2 绘制图标和菜单名称，支持滑动动画。
- 二级菜单框架：支持文字列表、选择框、滚动条和选项开关状态。
- 秒表页面：使用 TIM2 产生 10 ms tick，按键控制开始、暂停和清零。
- 图片/游戏页面：显示内置 `Wukong` 位图。
- 低功耗页面：关闭 OLED 并进入 STOP 模式。
- BMP280/BME280 驱动：已实现软件 I2C、寄存器访问和温压补偿，但尚未接入 Weather 页面。

## 开发约定

- 自写业务代码使用中文 Doxygen 风格注释。
- 函数注释必须包含 `@brief`、`@param`、`@return`。
- 修改注释时以当前代码实现为准，不保留过期说明。
- 第三方库和 ST 标准外设库不做无意义重注释，避免后续升级困难。
- 修改 Keil 工程时优先保持现有目录结构，避免破坏 `Project.uvprojx` 中的相对路径。

## 维护状态

当前仓库中的软件工程来自旧版 hWatch SE2 工程整理。代码中部分早期中文注释存在编码损坏，本次维护已给关键自写函数补充新的 UTF-8 中文 Doxygen 注释，但未修改任何业务逻辑。
