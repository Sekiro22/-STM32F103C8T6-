# Gerber 文件

本目录保存 hWatch PCB 的生产文件，可用于 PCB 打样平台下单。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `Gerber_PCB5_2024-08-15.zip` | PCB5 版本 Gerber 压缩包，可用于嘉立创等 PCB 厂商打样 |
| `可直接拿去嘉立创打板.txt` | 原项目留下的提示文件，表示该 Gerber 包可直接用于嘉立创下单 |

## 打样流程

1. 在 PCB 厂商平台选择上传 Gerber。
2. 上传 `Gerber_PCB5_2024-08-15.zip`。
3. 等待平台解析 PCB 层数、尺寸、孔位和阻焊等信息。
4. 下单前对照原理图和 3D/预览图检查接口方向、丝印、安装孔和电源网络。

## 维护注意

- 每次修改 PCB 后都应重新导出 Gerber，不要复用旧压缩包。
- 文件名建议保留 PCB 版本和日期，例如 `Gerber_PCBx_YYYY-MM-DD.zip`。
- 如果打样参数有特殊要求，如板厚、颜色、铜厚、阻抗、半孔等，应在 README 中补充。
